# crm_int

## About

crm_int is an e-commerce integration application.

The application uses the Allegro REST API to integrate Allegro marketplace data with an e-commerce platform.

## Purpose

The application is designed for marketplace integration, product data synchronization and related e-commerce operations.

## API

The application uses the official Allegro REST API and OAuth authorization.
